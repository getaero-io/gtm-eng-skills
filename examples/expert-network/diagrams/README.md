# Two diagrams, two questions

For an operator evaluating this example:

- **How does the expert flow work?** Find people → agree on work → review → invite back. The loop connects accepted work to repeat contribution. It shows the target flow, not a claim that every integration is live.
- **What does Deepline do?** A coding agent builds Plays using API Aggregation, Durable Execution and the Database. The diagram separates those capabilities without implying they run in sequence.

API names, database tables and deployment steps stay in the reference docs.
