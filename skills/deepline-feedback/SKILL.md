# deepline-feedback (retired)

## Quick Start

```bash
npm install -g deepline
deepline auth register --wait auto
deepline -h
```

This skill holds no instructions and will be removed.

- `deepline feedback send --help` explains when to report feedback or product
  friction, what evidence to include, and the flags.
- `deepline sessions send --help` explains sharing a session transcript and
  how to rate it.
