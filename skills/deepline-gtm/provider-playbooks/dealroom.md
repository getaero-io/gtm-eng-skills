# Dealroom

Connect your own Dealroom Premium API key before calling these tools. Deepline
charges no credits for Dealroom calls; your Dealroom contract governs usage.

Use the matching filter catalog before constructing a search filter, and look
up location IDs when filtering by geography. Search companies, founders,
investors, or funding transactions with a keyword. Use the returned Dealroom ID
for an entity lookup or related funding, investor, team, or investment reads.
Search and list results contain `total` and `items`; use `limit` and `offset`
to page through them. The API key limits calls to five requests per second.
