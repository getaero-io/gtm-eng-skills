# Crunchbase API

Connect a customer-owned Crunchbase API key before using these tools. Deepline does not provide a managed key or bill for Crunchbase calls. Crunchbase applies the customer's subscription access and quotas.

Search for an entity to obtain its Crunchbase UUID or permalink, then use entity lookup for details. Request only the `field_ids` and `card_ids` needed by the workflow. Search and lookup coverage depends on the customer's Crunchbase API package; a provider permission response may mean the key's package does not include that endpoint or field.

Source: [Crunchbase API documentation](https://data.crunchbase.com/docs/using-the-api) and [API package overview](https://data.crunchbase.com/docs/api-packages-overview).
