# Editable intro drafts

Generate drafts only when requested. Preserve `approved=false`; omit declined paths. Keep all messages local. A connection export verifies requester → connector membership at its export date, not connector → target familiarity or present willingness.

Use “I spotted that you're connected with” only with verified connector-target evidence. Otherwise use “I think you may know”. Use the target's name rather than guessing a pronoun. Replace bracketed fields only with supplied or cited facts; otherwise leave them editable. Do not infer an icebreaker from sensitive traits.

## Ask the connector

```text
Hey {connector first name} -- how are you keeping? [Optional verified icebreaker]

I think you may know {target full name} at {target company}.

Was wondering if you know them well enough to intro me?

If yes, even a little note would be really helpful. I can draft something below for you to review. Thanks again, and no pressure.

{requester first name}
```

Add “I have struggled to get in touch” only if the requester confirms it.

## Forwardable note for the connector to edit

```text
Hey {target first name} -- hope all's well!

I think it would be useful for you to connect with {requester first name}, [requester title] at {requester company}.

They've been working on [verified value proposition], and I think it could be an interesting conversation.

Connecting you here!
```

“Was chatting with … recently” requires confirmation from the connector. These are proposed messages, not records of chats or introductions. Show the score explanation separately; do not put private evidence or a numeric score in the ask.
